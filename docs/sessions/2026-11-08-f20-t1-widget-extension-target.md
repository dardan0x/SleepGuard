### Architecture Decisions
- **JSON snapshot in App Group over a shared SwiftData store**: leaves the store where it is (no file migration for existing installs) and avoids the known `events` faulting crash in a memory-limited extension. The widget only needs ~8 numbers.
- **Widget UI imports `DesignSystem`**: satisfies the localization rule (`Strings`) and the "derive from components" design decision (`SleepScoreGauge`, `MiniBarChart`, `Theme`). Risk: transitive Env/AudioEngine/Factory code in the extension binary. T5 measures memory against the ~30 MB widget budget; if over, revisit (e.g. split `Strings`/`Theme` into a lightweight target).
- **Kept Xcode's bundle ID** `com.dardan.SleepGuard.SleepGuardWidgets` rather than the planned `.Widgets`, to avoid registering a second App ID.
- **Entitlements file left at repo root**: moving it also requires changing `CODE_SIGN_ENTITLEMENTS`, which buys nothing.
