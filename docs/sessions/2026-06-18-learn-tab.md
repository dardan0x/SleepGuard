### Architecture Decisions
- **Top-level `feature_learn` key**: Chosen over extending the `tabs` array because the user explicitly asked for a key named `feature_learn` that carries both visibility and URL.
- **Boolean fallback for `feature_learn`**: Added so `true`/`false` values still toggle visibility without requiring a full JSON object.
- **New `Packages/Learn` feature package**: Keeps the web view code isolated and follows the project rule that feature packages only import Models, Env, and DesignSystem.

### Website-Side Context for Building the Learn Site

When you build the Learn website, use the `data-open-external="true"` attribute
on standard `<a>` tags to trigger `UIApplication.shared.open(_:)` from the app.

```html
<!-- Opens in Safari / system browser -->
<a href="https://example.com" data-open-external="true">Open externally</a>

<!-- Stays inside the app web view -->
<a href="/next-lesson">Next lesson</a>
```

Rules:
- Attribute value must be exactly `"true"`.
- Must be on an `<a>` tag with a real `href`.
- Does not intercept buttons, divs, or `window.location` changes.
- Styling works exactly like a normal link.

This is the contract the injected JavaScript in `LearnView.swift` expects.
