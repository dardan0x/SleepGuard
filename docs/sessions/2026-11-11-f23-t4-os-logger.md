### Completed
- F23-T4: all 76 `print` calls now go through `Log.<category>` (os.Logger), with a level chosen per call. Session and snore-event signpost intervals were added, and a CI rule keeps `print` out.

### Technical Details
- `Models/Sources/Helpers/Log.swift`: categories `audio`, `detection`, `session`, `interrupter`, `storage`, `playback`, `app`, plus `Log.signposter`.
- Interpolations: errors `privacy: .public`; numbers via `format: .fixed(precision:)`; enums via `String(describing:)`; strings stay private by default.
- Logger autoclosures need `self.`; `.swiftformat` gained `--selfrequired`. App-target files `import os` (member-import visibility).
- The per-result SoundAnalysis top-3 string is now built only in Debug.

### Architecture Decisions
- `Log` lives in Models because every target imports it. A separate logging package would be one more package for 35 lines.
- Errors are logged public, since an error description without its text is useless in a sysdiagnose. User content (names, paths, the token) stays private.
