### Technical Details — T12 decision
The plan's premise (4 identical private `ViewState` copies) no longer
holds after T1–T11: the surviving enums have different shapes —
`StatisticsDashboardView.ViewState` and `RecordingsListView.ViewState`
carry `.empty` plus distinct labeled payloads; `SessionDetailModel.ViewState`
has no `.empty` and a 3-field payload. A generic `AsyncViewState<Loaded>`
would either drop `.empty` (behavioral change) or need a second type, and
would churn every pattern-match site in three packages to save ~10
declaration lines. All three already satisfy the AGENTS.md load-state rule
(`.loading`/`.loaded`/`.error`). Decision: keep per-view enums; the
duplication the task targeted is already gone.
